# Baunthiyal Path Labs & Imaging Centre

A modern, responsive healthcare diagnostic laboratory website built with React and Vite.

The website is designed for Baunthiyal Path Labs & Imaging Centre to provide patients with an easy way to explore diagnostic tests, health packages, laboratory services, centres, healthcare partnerships, careers, and contact information.

---

## 🌐 Project Overview

The main goal of this project is to create a professional healthcare website that is:

- Simple for patients to use
- Fast and responsive
- Mobile-friendly
- Easy to maintain
- Modern but trustworthy
- Focused on diagnostic laboratory services
- Easy to expand with new tests, packages and centres

The design takes inspiration from modern healthcare and diagnostic websites while maintaining a clean and original visual identity for Baunthiyal Path Labs.

---

## 🎯 My Design Thinking

The main idea behind the website is:

> "Healthcare websites should feel trustworthy, simple and easy to use."

Instead of making the website crowded with information, the UI focuses on presenting important information in small, clear sections.

### Design Principles

1. **Trust**
   - Clean healthcare interface
   - Professional typography
   - Blue-based color palette
   - Certification and laboratory information

2. **Simplicity**
   - Simple navigation
   - Clear buttons
   - Short descriptions
   - Easy-to-understand sections

3. **Accessibility**
   - Large readable text
   - Clear buttons
   - High contrast
   - Mobile-friendly layouts

4. **Patient First**
   - Test search
   - Health packages
   - Home sample collection
   - Centre information
   - WhatsApp contact
   - Prescription upload
   - Easy contact form

5. **Responsive Design**
   - Desktop grid layouts
   - Tablet-friendly layouts
   - Mobile sliders
   - Touch-friendly cards
   - Responsive navigation
